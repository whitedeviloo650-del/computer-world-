Computer Guides for Beginners

Clear explanations to help you understand, use and look after a computer.

01

Hardware

Hardware is the physical equipment in a computer system.

  • Monitor: displays text and images
  • Keyboard: enters text and commands
  • Processor: carries out instructions
  • Storage: saves files and applications
02

Software

Software gives the computer instructions and tools to complete tasks.

  • Operating systems manage the device
  • Browsers open websites
  • Word processors create documents
  • Security software can help protect data
03

Computer care

Good habits can help keep a computer reliable.

  • Keep food and drinks away
  • Install trusted software updates
  • Back up important files
  • Use a strong password and lock the screen

Quick checklist

Save your work, back up important files when needed and sign out on shared devices.
